# 부산 집 찾기 서비스 (Find My Home)

## 📋 프로젝트 개요

**부산 집 찾기 서비스**는 12문항 설문을 통해 사용자에게 맞는 집 스타일을 진단하고, 부산 지역의 맞춤형 매물을 추천하는 Django 기반 웹 서비스입니다.

### 🎯 핵심 기능
- **12문항 설문 시스템**: 하드 필터 → 감성 프로필 → 현실 제약 단계별 설문
- **페르소나 매칭**: 6가지 부산 특화 페르소나 타입으로 집 스타일 진단
- **맞춤형 매물 추천**: 페르소나별 부산 지역 매물 추천
- **결과 공유**: 인스타그램, 카카오톡 등 SNS 공유 기능

### 🏗️ 기술 스택
- **Backend**: Django 4.2.7
- **Database**: SQLite (개발), PostgreSQL (배포 예정)
- **Frontend**: Bootstrap 5, Chart.js
- **Deployment**: Railway (예정)

## 🗄️ 데이터베이스 모델

### **Survey 앱 모델**
- **`Survey`**: 설문 참여자 정보 (이름, 이메일, 완료 상태)
- **`SurveyQuestion`**: 12문항 설문 문항 정보 (문항 ID, 내용, 타입, 단계)
- **`SurveyAnswer`**: 설문 답변 저장 (설문-문항 연결, 답변 내용)

### **Results 앱 모델**
- **`PersonaType`**: 6개 부산 페르소나 타입 정의
- **`AreaRecommendation`**: 지역 추천 정보 (점수, 장단점, 가격)
- **`SurveyResult`**: 설문 결과 (페르소나 매칭, 추천 지역/매물)

### **Property 앱 모델**
- **`Property`**: 부산 매물 정보 (가격, 면적, 페르소나 매칭)
- **`PropertyImage`**: 매물 이미지 관리
- **`PropertyInquiry`**: 매물 문의 관리

## 🎭 페르소나 타입

### **6가지 부산 특화 페르소나**

1. **해안가 라이프스타일형** 🏖️
   - 해운대/송정 지역 추천
   - 해안가 접근성 중시

2. **도심 라이프스타일형** 🏙️
   - 서면/부산진구 지역 추천
   - 도심 생활 편의성 중시
   - 학군 우수

3. **자연친화 크리에이티브형** 🌿

   - 자연환경 우수
   - 창작 공간 적합

4. **산업도시 자연친화형** 🏭
   - 사상구/강서구 지역 추천
   - 산업단지 근접성
   - 자연환경 조화

5. **항만 라이프스타일형** 🚢
   - 남구/동구 지역 추천
   - 항만 접근성 중시

6. **모던 미니멀형** 🏠
   - 북구/사하구 지역 추천
   - 통근 최적화

## 🚀 실행 방법

### **개발 환경 설정**

1. **가상환경 활성화**
```bash
source venv/bin/activate
```

2. **의존성 설치**
```bash
pip install -r requirements.txt
```

3. **데이터베이스 마이그레이션**
```bash
python manage.py migrate
```

4. **관리자 계정 생성**
```bash
python manage.py createsuperuser
```

5. **개발 서버 실행**
```bash
python manage.py runserver
```

### **접근 URL**
- **홈페이지**: http://localhost:8000/
- **관리자 페이지**: http://localhost:8000/admin/
- **설문 시작**: http://localhost:8000/survey/
- **매물 목록**: http://localhost:8000/properties/
